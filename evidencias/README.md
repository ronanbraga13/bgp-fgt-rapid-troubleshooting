# Upload das evidências (Caso 01)

Esta pasta receberá os **11 PNGs** do arquivo `bgp-fgt-rapid-troubleshooting-evidencias.zip`.

1. Extraia o ZIP disponibilizado na conversa.
2. No GitHub, abra a pasta **`evidencias/`** deste repositório.
3. Escolha **Add file → Upload files**.
4. Arraste **os 11 arquivos PNG de dentro da pasta `evidencias/` extraída** para a tela de upload (não inclua outra subpasta `evidencias/`).
5. Confirme o commit no branch `main`.

Os nomes dos PNGs já coincidem com as referências em `README.md`, `EVIDENCIAS.md` e `CENARIOS/01-bgp-bad-peer-as.md`. **Não é necessário editar os arquivos Markdown** após enviar as capturas.

A imagem **`08-debug-bgp-bad-peer-as-destacado.png`** tem uma marcação amarela nas linhas `Bad Remote-AS` e `NOTIFICATION 2/2`, conforme solicitado.
