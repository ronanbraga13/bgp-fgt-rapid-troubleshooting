# Caso 02 — Pasta de evidências

As **10 imagens PNG** do Cenário 02 devem ficar diretamente nesta pasta, sem subpastas extras.

1. Baixe e extraia o arquivo `lab02-bgp-neighbor-ip-incorreto-evidencias.zip` disponibilizado na conversa.
2. Abra `evidencias/lab02/` neste repositório e selecione **Add file → Upload files**.
3. Faça upload dos **10 PNGs** (de `00-` até `09-`). Não envie o ZIP como único arquivo.
4. Confirme o commit na branch `main`.

Os links em `README.md`, `EVIDENCIAS.md` e `CENARIOS/02-bgp-neighbor-ip-incorreto.md` já estão prontos. O debug e a validação final têm as mensagens importantes destacadas em amarelo.
